# Зерно 35

Плёночная камера в телефоне. Выбираешь одну из 13 камер, снимаешь, и кадр сразу проявляется: зерно, цвет плёнки, виньетка, засвет, оранжевая дата в углу и рамка с перфорацией.

Камеры: Canon AE-1, Nikon F3, Olympus OM-1, Pentax K1000, Minolta SR-T 101, Fujica ST801, Contax AX, Olympus Pen, Rollei 35, Зенит-ЕТ, Kodak F9, Lomography LC-Wide, Kodak M35.

## Что умеет

- Живой видоискатель: эффект выбранной камеры виден ещё до съёмки, рамкой показан формат кадра (3:2, у Olympus Pen 3:4).
- После съёмки кадр открывается на весь экран с кнопкой сохранения: на iPhone в «Фото», на Android в галерею.
- Плёнка на 36 кадров хранится в телефоне. Любой кадр можно перепроявить другой камерой или плёнкой.
- Работает без интернета после первого открытия.
- Ставится на главный экран как обычное приложение.

## Как выложить на GitHub Pages

Нужен бесплатный аккаунт на github.com. Интерфейс GitHub на английском, поэтому названия кнопок ниже даны так, как они там написаны.

1. Войди на github.com, нажми **New repository**. Имя: `zerno35`, видимость **Public**, нажми **Create repository**.
2. На странице репозитория нажми **uploading an existing file** (или **Add file → Upload files**).
3. Распакуй архив, открой папку `zerno35` и перетащи в окно браузера **все файлы из неё** (не саму папку). Внизу нажми **Commit changes**.
4. Открой **Settings → Pages**. В блоке **Build and deployment** выбери **Source: Deploy from a branch**, ветку **main** и папку **/ (root)**, нажми **Save**.
5. Через 1–2 минуты обнови страницу Pages. Сверху появится адрес вида `https://ТВОЙ-ЛОГИН.github.io/zerno35/`.

Бесплатный GitHub Pages работает только с публичными репозиториями. Код при этом виден всем, а твои фотографии нет: они никогда не покидают телефон.

## Как поставить на телефон

**iPhone:** открой адрес в Safari → кнопка «Поделиться» → «На экран „Домой“». Запускай с иконки, тогда камера откроется без панелей браузера.

**Android:** открой адрес в Chrome → в приложении появится кнопка «Установить» (или меню ⋮ → «Установить приложение»).

При первом нажатии «Включить камеру» телефон спросит разрешение на камеру. Если случайно запретил, разреши в настройках браузера для этого сайта. Пока доступа нет, спуск открывает обычную камеру телефона.

## Как обновить

Загрузи новые файлы поверх старых через **Add file → Upload files** и нажми **Commit changes**. Телефон подхватит новую версию при следующем запуске с интернетом (иногда нужно открыть приложение дважды). Если обновление не появилось, открой `sw.js` и поменяй `zerno35-v1` на `zerno35-v2`.

## Где хранятся фото

Всё считается на самом телефоне, на сервер ничего не загружается. Плёнка хранится в памяти браузера: если удалить приложение или очистить данные сайта, кадры из плёнки пропадут. Удачные кадры сразу сохраняй в галерею.
